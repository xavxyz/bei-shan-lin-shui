# Proposer au calligraphe

Une proposition se tranche d'un regard : le calligraphe a sous les yeux tout ce qu'il lui faut pour décider, sans rien chercher ni se rappeler. « ok » accepte tout.

```
## <n>/<total> — <titre> · `<slug>`
statut · date · format · projet ; ce que montre le scan, s'il y en a un.

❓ **a - <question>**
➡️ <recommandation>
```

Une question par lettre, chacune avec sa recommandation. Elle porte ce qui permet d'y répondre :

- **Un passage chinois** vient avec sa traduction française, vers par vers, en tableau `原文 | traduction` : celle du texte de référence (`docs/sources/`) quand il existe, sinon une traduction de travail, qui n'entre pas dans la pièce (ADR 0002). Le calligraphe juge le sens, pas seulement les caractères.
- **Un format proposé** vient avec sa page `pnpm grilles` (skill `grilles`), un candidat par format comparé : la notation seule ne se voit pas.
- **Un terme technique** s'explique en français courant, dans la question même : « le 道藏 écrit 个, ton papier 箇 : lequel garder ? ».
