# 清靜經 — texte de référence

Le 《太上老君說常清靜經》, traduit membre par membre pour choisir l'étendue de la pièce `tai-shang-lao-jun-shuo-chang-qing-jing-jing` (lot 4 du plan d'import). Le texte est celui du 正統道藏 sur zh.wikisource (`太上老君說常清靜經`, `action=raw`), les leçons recoupées sur les deux commentaires du 道藏 qu'on y trouve, le 《太上老君說常清靜經註》 attribué à 杜光庭 (唐) et le 《太上老君說常清靜經註》 de 李道純 (元) (`太上老君說常清靜經杜光庭註`, `太上老君說常清靜經李道純註`).

Traductions de travail, faites par des agents : la traduction qui accompagne une pièce s'écrit à la main. Les ➡️ marquent les étendues candidates ; les étendues retenues sont dans les pièces.

## 《太上老君說常清靜經》 · `tai-shang-lao-jun-shuo-chang-qing-jing-jing`

**Source :** anonyme, sans doute fin des 唐 (premier commentaire attribué à 杜光庭, 850–933), 正統道藏, 洞神部. Le 經 proper va de 老君曰：大道無形 à 得悟道者，常清靜矣 : **391 caractères**, dont les deux 老君曰 (385 sans eux). Il est suivi de trois postfaces d'attribution et de mérites (葛玄, 左玄真人, 正一真人, 195 caractères), données après la table : elles ne sont pas du 經, 李道純 ne les commente pas, 杜光庭 les commente. La page wikisource donne deux textes qui ne s'accordent pas : la version en prose courante suit la vulgate, la version en colonnes (豎排版) suit le 道藏 et les deux commentaires ; on suit celle-ci. Leçons retenues : 而**心**擾之 (vulgate : 而**情**擾之) ; 清者濁之源，**動者靜之基** (vulgate : **靜者動之基**) ; **真常**應物 (vulgate et texte de 李道純 : **真靜**應物, mais son commentaire dit 真常應物) ; 名**為**得道 (vulgate : 名**謂**得道). Graphies : 慾 gardé partout (李道純 alterne 欲 / 慾) ; 升 de wikisource, là où 杜光庭 écrit 昇 ; 鍊 gardé. Le 葛玄 de la postface est 葛翁 dans beaucoup d'éditions courantes.

| 原文 | traduction |
| --- | --- |
| 老君曰： | Le Vieux Seigneur (_Lǎojūn_ 老君, Laozi divinisé) dit : |
| ➡️ 大道無形，生育天地； | La grande Voie est sans forme : elle engendre et nourrit le ciel et la terre ; |
| ➡️ 大道無情，運行日月； | la grande Voie est sans sentiments (_qíng_ 情, affects, partialité) : elle fait tourner le soleil et la lune ; |
| ➡️ 大道無名，長養萬物； | la grande Voie est sans nom : elle fait croître et nourrit les dix mille êtres. |
| ➡️ 吾不知其名，強名曰道。 | Je ne sais pas son nom ; à grand-peine je la nomme « Voie ». |
| 夫道者：有清有濁，有動有靜； | La Voie a du clair et du trouble, du mouvement et du repos. |
| 天清地濁，天動地靜； | Le ciel est clair, la terre trouble ; le ciel se meut, la terre repose. |
| 男清女濁，男動女靜。 | L'homme est clair, la femme trouble ; l'homme se meut, la femme repose. |
| 降本流末，而生萬物。 | Descendant de la racine (_běn_ 本), s'écoulant vers les branches (_mò_ 末), elle engendre les dix mille êtres. |
| ➡️ 清者濁之源，動者靜之基。 | Le clair est la source du trouble ; le mouvement est le fondement du repos. |
| ➡️ 人能常清靜，天地悉皆歸。 | Que l'homme sache demeurer constamment clair et calme (_qīngjìng_ 清靜, clarté et quiétude), et le ciel et la terre tout entiers reviennent à lui. |
| 夫人神好清，而心擾之； | L'esprit (_shén_ 神) de l'homme aime la clarté, mais le cœur (_xīn_ 心, le mental) le trouble ; |
| 人心好靜，而慾牽之。 | le cœur de l'homme aime le repos, mais les désirs (_yù_ 慾) l'entraînent. |
| 常能遣其慾而心自靜， | Qui sait toujours congédier ses désirs, son cœur de lui-même s'apaise ; |
| 澄其心而神自清。 | qui laisse son cœur se décanter, son esprit de lui-même s'éclaircit. |
| 自然六慾不生，三毒消滅。 | Alors d'eux-mêmes les six désirs (_liùyù_ 六慾, ceux des six sens) ne naissent plus, les trois poisons (_sāndú_ 三毒, avidité, colère, égarement) se dissipent. |
| 所以不能者，為心未澄，慾未遣也。 | Si l'on n'y parvient pas, c'est que le cœur n'est pas encore décanté, que les désirs ne sont pas encore congédiés. |
| 能遣之者， | Qui sait les congédier : |
| ➡️ 內觀其心，心無其心； | regarde au-dedans son cœur : le cœur n'a pas de cœur ; |
| ➡️ 外觀其形，形無其形； | regarde au-dehors sa forme : la forme n'a pas de forme ; |
| ➡️ 遠觀其物，物無其物。 | regarde au loin les choses : les choses n'ont pas de chose. |
| ➡️ 三者既悟，唯見於空。 | Ces trois une fois compris, il ne voit plus que le vide (_kōng_ 空). |
| 觀空亦空，空無所空； | Il regarde le vide : le vide aussi est vide ; le vide n'a rien qu'il rende vide ; |
| 所空既無，無無亦無； | ce qui était rendu vide n'étant plus, le « non du non » (_wúwú_ 無無) lui non plus n'est pas ; |
| 無無既無，湛然常寂； | le non du non n'étant plus, c'est la limpidité (_zhànrán_ 湛然), le silence constant (_jì_ 寂) ; |
| 寂無所寂，慾豈能生？ | silence sans rien qui soit fait silence : comment le désir pourrait-il naître ? |
| 慾既不生，即是真靜。 | Le désir ne naissant plus, c'est la vraie quiétude (_zhēnjìng_ 真靜). |
| 真常應物，真常得性； | Le vrai et constant (_zhēncháng_ 真常) répond aux choses ; le vrai et constant obtient la nature (_xìng_ 性). |
| 常應常靜，常清靜矣。 | Répondre constamment, reposer constamment : c'est la constante clarté-quiétude. |
| 如此清靜，漸入真道； | Clair et calme de la sorte, on entre peu à peu dans la vraie Voie ; |
| 既入真道，名為得道， | entré dans la vraie Voie, on dit qu'on a « obtenu la Voie » (_dédào_ 得道) ; |
| 雖名得道，實無所得； | mais si on le dit, en vérité on n'a rien obtenu ; |
| 為化眾生，名為得道； | c'est pour convertir les êtres (_zhòngshēng_ 眾生) qu'on dit « obtenir la Voie ». |
| 能悟之者，可傳聖道。 | Qui sait s'éveiller à cela peut transmettre la Voie des saints. |
| 老君曰：上士無爭，下士好爭； | Le Vieux Seigneur dit : l'homme supérieur ne dispute pas, l'homme inférieur aime disputer ; |
| 上德不德，下德執德； | la vertu supérieure ne se tient pas pour vertu, la vertu inférieure s'agrippe à la vertu ; |
| 執著之者，不名道德。 | ceux qui s'y agrippent, on ne les dit pas de la Voie et de la Vertu. |
| 眾生所以不得真道者，為有妄心。 | Si les êtres n'obtiennent pas la vraie Voie, c'est qu'ils ont le cœur égaré (_wàngxīn_ 妄心, cœur d'illusion). |
| 既有妄心，即驚其神； | Ayant le cœur égaré, ils effarouchent leur esprit ; |
| 既驚其神，即著萬物； | l'esprit effarouché, ils s'attachent aux dix mille choses ; |
| 既著萬物，即生貪求； | attachés aux choses, naît la convoitise ; |
| 既生貪求，即是煩惱； | la convoitise née, ce sont les tourments (_fánnǎo_ 煩惱, les passions qui affligent) ; |
| 煩惱妄想，憂苦身心； | tourments et pensées d'illusion affligent le corps et le cœur ; |
| 便遭濁辱，流浪生死， | alors on subit souillure et opprobre, on erre de naissance en mort, |
| 常沉苦海，永失真道。 | sombrant sans cesse dans la mer des souffrances, perdant à jamais la vraie Voie. |
| ➡️ 真常之道，悟者自得。 | La Voie vraie et constante, qui s'y éveille l'obtient de lui-même. |
| ➡️ 得悟道者，常清靜矣。 | Qui a obtenu l'éveil à la Voie est constamment clair et calme. |

- 吾不知其名，強名曰道 reprend le 《道德經》 25 (吾不知其名，字之曰道，強為之名曰大) ; 上士 / 下士 le 41 ; 上德不德 le 38, où 下德不失德 devient ici 下德執德.
- Le vocabulaire est pour moitié bouddhique : 六慾, 三毒, 空, 眾生, 煩惱, 妄想, 苦海, 流浪生死. La gradation 觀空亦空 … 無無亦無 suit la négation de la négation des 般若.
- 清者濁之源，動者靜之基 : la vulgate inverse le second membre (靜者動之基), ce qui casse le parallélisme avec 清者濁之源 (le premier terme du couple engendre le second) ; 杜光庭 et 李道純 lisent 動者靜之基.
- 物無其物 : littéralement « la chose n'a pas sa chose » ; même tournure pour le cœur et la forme.
