# Les cinq pas se travaillent à la suite sur un même caractère

戈 écrit en général un caractère dans les cinq pas, l'un après l'autre, du régulier à la cursive folle. Le travail de limpidité porte sur le régulier, la base dont le reste découlera : une leçon peut donc s'appuyer sur ce rituel (régulier d'abord, puis observer ce qui passe dans les pas suivants) au lieu d'inventer une routine à part.
