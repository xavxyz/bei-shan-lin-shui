# La consigne des verticaux purs vaut pour le régulier, pas pour 方圓

Verticaux purs et horizontaux montants, c'est la consigne de 山山 pour le régulier. Elle ne contredit pas 竪橫 (horizontaliser les verticaux, verticaliser les horizontaux), qui vaut pour la cursive dans la méthode 方圓. Une leçon qui rapproche les deux doit nommer le style auquel chaque règle s'applique.
